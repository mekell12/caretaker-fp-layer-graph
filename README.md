# Caretaker FP Layer Graph
A Processing program that generates PNG images of layer graphs for the purposes of making sample guides for Caretaker Fan Projects.

How to use:
* If you haven't already, [download Processing](https://processing.org/download)
* Download the repository
* Open the program in Processing
* Add the layer activity durations, cut times, and reversed portion durations in `durations`, `cutoffs`, and `reverses` arrays, which you can then link to `Layer` objects in `layers`
* Adjust the control variables to your liking (SIZE MUST BE ADJUSTED IN `setup()`, IN THE SIZE FUNCTION WHICH APPEARS AS `size(width, height, P2D);`)
* Run the program, then click the program window, and check the sketch folder, your graph should appear as `YourProcessingFolder/Caretaker_FP_Layer_Graph/Your track layer graph.png`

I am open to improvements on the guide, I am not the best of GitHub users myself!
